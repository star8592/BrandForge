# BrandForge

AI-powered brand asset discovery system.

## Goal

BrandForge helps discover and evaluate long-term technology brand assets:

- Domain availability
- GitHub namespace availability
- Brand collision signals
- Candidate generation
- AI-assisted scoring

## Vision

A brand research agent for future AI infrastructure companies.

## Architecture

```
BrandForge
├── generator      candidate generation
├── domain         domain scanner
├── github         GitHub namespace scanner
├── scorer         brand scoring engine
└── report         HTML/JSON reports
```
